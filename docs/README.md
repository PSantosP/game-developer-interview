## 이번 개정에서 달라진 점

기존 초안의 개념 요약과 84문항은 유지하고, 각 주제에 예제·해설을 연결했습니다. C++ 15개 실행 예제, Unreal 18개 구현 사례, 12차시의 단계별 실습 안내를 추가했습니다. 참조 수명 설명의 예외와 공식 참고 링크의 절 주소도 수정했습니다.

원문보다 낫다는 평가는 분량으로 결정하지 않습니다. 이 개정의 목표는 요약 문장을 외우는 데서 멈추지 않고, 작은 예제의 결과를 예측하고 직접 변형할 수 있게 하는 것입니다.

## 원문 주제에서 어떻게 확장했나요?

| 원문 질문 모음집의 접근 | 확장에서 대응하는 내용 |
|---|---|
| GC 원리와 호출 시점 관찰 | C++ RAII와 Unreal GC를 구분하고 수명 로그 관찰 |
| Fake Null 등 유효성 가정 검증 | Destroy 이후 상태, 약한 참조, GC 추적 조건 검증 |
| 메모리 할당과 최적화 실습 | vector 재할당, 컨테이너 선택, 에셋 로딩 측정 |
| Rendering과 프레임 관찰 | Unreal의 CPU/GPU 비용 및 렌더링 경로 관찰 |
| 경험·구현·조사 질문 | 각 차시에 같은 유형의 질문과 결과 확인 기준 배치 |

엔진별 동작을 일대일로 치환하지 않습니다. C# GC의 답을 단어만 바꿔 Unreal GC의 답으로 사용하면 안 됩니다. 기존 객체지향·디자인 패턴·운영체제·네트워크는 차시에 연결한 원문과 함께 공부합니다.
